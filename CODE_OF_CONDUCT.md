# Code of Conduct

## Our Pledge

We are committed to providing a respectful, professional, and technically focused
environment for everyone participating in this project.

This project exists to build and maintain secure, local-first software.
Discussions and contributions should reflect that goal.

---

## Expected Behavior

Participants are expected to:
- Be respectful and constructive
- Focus on technical merit and factual discussion
- Accept constructive criticism
- Respect differing viewpoints and experience levels
- Communicate clearly and professionally

---

## Unacceptable Behavior

Unacceptable behavior includes:
- Harassment, insults, or personal attacks
- Discriminatory or offensive language
- Trolling, deliberate disruption, or bad-faith participation
- Publishing private information without consent
- Attempts to pressure maintainers into decisions

---

## Scope

This Code of Conduct applies to:
- GitHub issues
- Pull requests
- Discussions
- Project-related communication channels

---

## Enforcement

Project maintainers are responsible for enforcing this Code of Conduct.
They may take appropriate action, including:
- Warning the offender
- Removing comments or contributions
- Temporarily or permanently banning participants

Decisions are made in the interest of project security, stability, and long-term maintainability.

---

## Reporting

For public moderation requests, contact the maintainers in the relevant [fork issue](https://github.com/dev-zetta/LSCamoflash/issues) or [pull request](https://github.com/dev-zetta/LSCamoflash/pulls). Do not post private information. This fork does not currently publish a dedicated private conduct-report contact; the original upstream email is not a contact for this fork. Security vulnerabilities use the separate [private security channel](SECURITY.md).
