About this dashboard

The Fullhan dashboard starts manually from the SD card and leaves the stock camera application in control. Status refreshes every 15 seconds while the page is visible. Recording lists refresh only when you request them.

If a service is unavailable, check the manual startup output and the pilot's bounded startup log. This interface cannot reset the camera, modify its network or install firmware.
