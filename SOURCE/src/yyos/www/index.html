Camera controls

Use the stock app for supported camera settings. This dashboard provides status only; settings, PTZ, reboot and firmware updates are unavailable. The Recordings page provides read-only raw downloads.

Local RTSP and ONVIF were tested on this firmware alongside the Tuya app. Use the camera’s separate streaming credentials below. This dashboard cannot enable or change native services. Support is experimental; direct VLC playback and long-term reliability still need investigation.

    About this interface

    This isolated YYOS interface leaves the stock camera application, configuration and networking in control. It refreshes status every 15 seconds while visible. Startup and shutdown affect only its owned HTTP process.

    The bounded startup log contains fixed lifecycle messages. Credentials and firmware backups are outside the served directory. Keep this experimental HTTP interface on the intended trusted LAN.
