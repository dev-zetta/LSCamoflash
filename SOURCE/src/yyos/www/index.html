About this interface

This isolated YYOS interface leaves the stock camera application, configuration and networking in control. It refreshes status every 15 seconds while visible. Startup and shutdown affect only its owned HTTP process.

The bounded startup log contains fixed lifecycle messages. Credentials and firmware backups are outside the served directory. Keep this experimental HTTP interface on the intended trusted LAN.
