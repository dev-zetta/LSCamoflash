# Get help with LSCamoflash

Start with the [installation guide](docs/installation.md), [configuration guide](docs/configuration.md) and [troubleshooting guide](docs/troubleshooting.md). Check the [compatibility notes](docs/integration.md) for your exact firmware; similar product names can hide different hardware.

## Report a problem or request a feature

Open an issue in **[dev-zetta/LSCamoflash](https://github.com/dev-zetta/LSCamoflash/issues)**. This is the support tracker for the fork and its releases.

Include:

- Camera model, article number and hardware revision if known.
- Exact stock firmware and the installed LSCamoflash version.
- SD layout, selected operating mode and what you expected to happen.
- Steps to reproduce and relevant error messages.
- Redacted current and previous startup logs where useful.

Keep firmware dumps, Wi-Fi credentials, account databases, device identifiers and raw logs private. A checksum and a short redacted excerpt are often enough to start investigating. The [camera diagnostics guide](docs/camera-3007325.5.md#first-boot-and-diagnostics) lists the relevant runtime logs.

## Security reports

Do not post vulnerabilities in public issues. Use the fork's private reporting channel described in [SECURITY.md](SECURITY.md).

## Scope and response times

Support is voluntary and provided on a best-effort basis for this fork's installation, runtime, build tools, documentation and compatibility reports. There is no guaranteed response time or commercial support commitment.

Vendor cloud outages, original vendor firmware and unsupported hardware can require information or changes outside this project. Where hardware or exact firmware is unavailable, a report can remain open for evidence rather than a verified fix. See the [usage policy](USAGE_POLICY.md) and [code of conduct](CODE_OF_CONDUCT.md).
